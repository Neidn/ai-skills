# 사례: 공개된 BitMEX 계좌 "aoa" (2018-03 ~ 2021-12)

트레이더 본인이 서한과 함께 공개한 BitMEX 체결 내역(execution CSV 4개, 체결 144만 건,
주문 2.3만 건)과 지갑 내역이다. 이 스킬의 절차를 처음부터 끝까지 적용한 예시로 읽는다.
수치는 `reconstruct_trades.py --format bitmex`와 별도 분석에서 실측한 값이다.

공개자 본인이 서한에서 **"이 자료로 만든 매매봇은 수익이 날 것 같으면 내가 먼저 만들어
돌렸을 것"**이라고 경고했다. 이 사례의 결론도 같다 — 판단은 못 옮기고 구조만 옮긴다.

## 1. 정규화에서 확인한 것

- 주문 2.3만 건 전부 `text = "Submission from www.bitmex.com"` → **웹 UI 수동 매매**. API 주문 0건.
- 체결 단위 데이터. 거래대금의 92%가 XBTUSD(인버스), 6.5%가 ETHUSD(쿼토).
- 마진 통화는 BTC. 분석은 BTC 기준으로 했다.

## 2~3. 재구성과 대조

- 트레이드 3,176건(미청산 9건 제외).
- 심볼별로 `재구성 + 펀딩 = 지갑 실현손익`이 일치했다. 남은 차이는 기간 말 XBTUSD 미청산
  롱 하나의 부분 실현분이었다.

### 읽은 것

- **레버리지를 줄인 시점이 보인다.** 2018년 고노출(p90 13배) 구간에서 청산 체결 57건과
  하루 −84%가 나온 뒤, 2019년부터 노출 중앙값이 1배 근처로 내려왔다. 이후 청산은
  거의 없다.
- **손절 주문을 거의 안 쓴다.** Stop 주문이 들어간 트레이드는 1.2%다. 리스크는
  손절이 아니라 노출 크기로 관리했다.
- **손실을 더 오래 들고 물을 탄다.** 2019년 이후 손실 트레이드의 보유시간 중앙값(11.8h)이 수익
  트레이드(4.7h)의 약 2.5배다. 크기 상위 절반 XBTUSD 트레이드의 60~70%는 평균진입가가 첫 진입가보다 불리했다.
- **승률이 높고 payoff < 1.** 평균 손실이 평균 이익보다 크다. 이 구조는 승률이 떨어지면
  바로 무너진다. 2021년 10~12월에는 3개월 연속 약 −17%였다.
- **돈은 1~3일 보유 트레이드에서 나왔다.** 15분 미만 트레이드가 건수로는 41%지만
  순손익 기여는 4%였다.
- **롱/숏 약 50:50**, 진입 직전 24시간 움직임과 반대 방향 진입이 52~56%로 약한 역추세
  성향이다.

### 진입 규칙 추출 시도

진입 시점 지표(최근 수익률, RSI, 이평 대비 위치, 변동성)로 롱/숏 방향을 예측한 AUC가
**0.56~0.58**이었다. 재량으로 판정했다.

보인 경향은 "상승 추세(200MA 위, 7일 상승) 속 단기 눌림(4시간 −0.6%, RSI 45)에서 롱"
정도다. 숏은 뚜렷한 패턴이 없었다.

한계: 시세 캔들이 없어 체결가로 시간봉을 만들었고, 전체 시간의 14%만 채워졌다. 진입
*시점* 예측 AUC(0.83)는 이 왜곡 때문에 기각했다(4절 함정).

## 5. 이식 판정

| 항목 | 판정 | 옮긴 형태 (선물 봇 예) |
|---|---|---|
| 계좌 단위 노출 ≈ 1배 | **구조** | 열린 포지션 명목 합계 ≤ 1.0 × 자산. 초과분은 진입 수량을 줄이거나 건너뜀 |
| 지정가·maker 진입 | **구조** | post-only 진입, 호가 재제시, 가격 이탈 시 포기 |
| 분할 청산 3~6회 | **구조** | TP 3단계 |
| 큰 낙폭 뒤 축소 | **구조** | 고점 대비 10% 낙폭이면 신규 진입 48시간 정지 |
| BTC·ETH 집중 | 구조 (계좌가 작으면 최소 주문 단위가 막는다) | 보류 |
| 물타기·무손절 | **조건부** — 저노출과 재량적 포기 판단이 전제 | 옮기지 않음. 노출 상한 없이 옮기면 위험이 커진다 |
| 롱/숏 50:50, 역추세 | 판단 | 옮기지 않음. 내 시스템의 측면별 실측이 우선 |
| 진입 방향·타이밍 | **판단** (AUC 0.56~0.58) | 옮기지 않음. 눌림목 롱은 기존 전략과 같은 가설로만 기록 |

이 판정은 "aoa처럼 벌 수 있다"를 뜻하지 않는다. 손실 분포의 꼬리를 줄이는 구조를
가져왔다는 뜻이다. 각 항목은 shadow/실거래 표본으로 다시 검증한다.
