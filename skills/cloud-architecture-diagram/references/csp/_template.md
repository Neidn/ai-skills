## 3. 구성도에서 틀리기 쉬운 것

이 파일에서 가장 값어치 있는 부분. 실제로 틀려본 것만 적는다.
아래 관점으로 점검하면 대부분 나온다.

- 네트워크 계층 경계 (무엇이 VPC 안이고 무엇이 밖인가)
- 존/AZ와 서브넷의 관계
- 전용 서브넷이 필요한 리소스가 있는가
- 퍼블릭/프라이빗 판단 기준
- 보안 경계가 적용되는 단위 (인스턴스 단위인가 서브넷 단위인가)
- 여러 서브넷에 걸치는 리소스를 어디에 둘 것인가
- 계정/구독/프로젝트 같은 상위 경계
