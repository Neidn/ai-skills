# 디자인 토큰

값은 여기서만 고른다. 새 값이 필요하면 지어내지 말고, 스케일 안에서 가장 가까운 값을 쓰거나
사용자에게 확인한 뒤 이 파일에 추가한다.

## 타이포그래피

본문 1종 + 코드 1종. 그 이상 섞지 않는다.

| 역할 | 크기(pt/px) | 굵기 | 줄간격 | 문단 위 간격 |
|---|---|---|---|---|
| H1 (문서 제목) | 28 / 28px | 700 | 1.2 | — |
| H2 (장) | 22 / 22px | 700 | 1.25 | 32 |
| H3 (절) | 17 / 17px | 600 | 1.3 | 24 |
| H4 (항) | 14 / 14px | 600 | 1.4 | 16 |
| 본문 | 11 / 16px | 400 | 1.6 | 8 |
| 보조·캡션 | 9 / 13px | 400 | 1.5 | 4 |
| 코드 | 10 / 14px | 400 | 1.5 | — |

- 본문 글꼴: 한글 `Pretendard`/`본고딕(Noto Sans KR)`, 라틴 `Inter`/시스템 산세리프. 문서 톤이
  격식이면 명조 계열(본명조)도 가능하나 한 문서 안에서는 하나로 통일.
- 코드 글꼴: `JetBrains Mono`/`D2Coding`/`Consolas` 등 고정폭 1종.
- 제목을 본문보다 **최소 1.3배** 크게 둬서 위계를 크기로 만든다.

## 간격 스케일

4의 배수만 쓴다. 이 사이의 값(예: 10, 18)은 쓰지 않는다.

```
4  8  12  16  24  32  48  64
```

- 문단 사이: 8
- 항목(H4) 블록 사이: 16
- 절(H3) 사이: 24
- 장(H2) 사이: 32
- 표·그림 위아래 여백: 16
- 페이지 여백(인쇄): 상하 20mm, 좌우 25mm

## 색 역할

색은 이름이 아니라 **역할**로 고른다. 아래 8개 역할이 전부다.

| 역할 | 라이트 값 | 용도 |
|---|---|---|
| `text` | `#1A1A1A` | 본문 |
| `text-muted` | `#6B7280` | 보조·캡션·비활성 |
| `border` | `#E5E7EB` | 표·구분선 |
| `surface` | `#F9FAFB` | 코드블록·콜아웃 배경 |
| `accent` | `#0067AC` | **브랜드 슬롯 = 안랩클라우드메이트 시그니처 블루.** 링크·강조·헤더 포인트 |
| `info` | `#0EA5E9` | 참고 콜아웃 |
| `warning` | `#F59E0B` | 주의 콜아웃 |
| `danger` | `#DC2626` | 경고·금지 콜아웃 |
| `success` | `#16A34A` | 완료·정상 콜아웃 |

- 한 문서의 강조색은 `accent` 하나. 상태 4색은 콜아웃·상태 표기에만 쓰고 본문 강조로 쓰지 않는다.
- 텍스트/배경 대비는 최소 4.5:1(WCAG AA)을 지킨다.

## 표

- 헤더 행만 배경(`surface`)+굵게. 나머지는 가로선(`border`)으로만 구분.
- 세로선은 넣지 않는다(정말 촘촘한 수치표 예외).
- 행이 8줄을 넘으면 얼룩말 줄무늬(`surface` 교차)를 넣어 눈이 줄을 놓치지 않게 한다.
- 숫자 열은 우측 정렬, 텍스트 열은 좌측 정렬. 단위는 헤더에 표기.
- 셀 안 줄바꿈은 허용하되, 한 셀에 문장 3개 넘으면 표가 아니라 목록으로 바꾼다.

## 콜아웃

종류는 4개뿐. 왼쪽 색 막대 + 옅은 배경 + 라벨.

| 라벨 | 색 역할 | 언제 |
|---|---|---|
| 참고 | `info` | 알아두면 좋은 부가 정보 |
| 주의 | `warning` | 실수하기 쉬운 지점, 되돌리기 번거로운 작업 |
| 경고 | `danger` | 하면 안 되는 것, 데이터·서비스 손실 위험 |
| 완료/정상 | `success` | 기대 상태, 성공 판정 기준 |

Markdown에서는 색을 못 쓰므로 인용구 + 볼드 라벨로 대체한다:
`> **주의** — 재기동 전 세션을 먼저 비운다.`

## 코드블록

- 배경 `surface`, 모서리 살짝 둥글게(4px), 좌우 패딩 16.
- 언어를 명시(```bash 등)해 하이라이트가 걸리게 한다.
- 실행 명령과 출력은 블록을 나눈다. 출력 전체를 붙이지 말고 판단에 필요한 줄만 남긴다.
- 인라인 코드(`이런 것`)는 명령·경로·값에만. 강조 용도로 남발하지 않는다.

## 다크 모드(선택)

화면 전용 문서라면 각 색 역할의 다크 값을 `assets/design-tokens.json`의 `dark`에 둔다.
인쇄·배포용 문서는 라이트 고정으로 둔다.
