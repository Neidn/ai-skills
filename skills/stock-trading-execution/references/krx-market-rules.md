## 가격 제한

- **가격제한폭:** 기준가 대비 ±30%. 상·하한가에 잠기면 반대 방향 체결이 거의 없다.
- **VI(변동성 완화장치):** 단기 급변 시 일정 시간 단일가 매매로 바뀐다.
  - 동적 VI: 직전 체결가 대비 일정 비율 이상 변동 (종목군·세션별 비율 다름)
  - 정적 VI: 기준가(전일 종가 또는 직전 단일가) 대비 ±10% 이상 변동
  - 발동 시 약 2분 단일가 + 랜덤 엔드. 정확한 비율·시간은 KRX 문서로 확인한다
- **단기과열종목·투자경고/위험:** 단일가 매매(일정 주기)나 증거금 100% 같은 제약이
  붙는다. 시장경보 지정 목록을 매일 조회한다.

## 호가단위 (KOSPI·KOSDAQ 통합, 2023-01 이후. 확인 필요)

| 가격 | 호가단위 |
|---|---|
| 2,000원 미만 | 1원 |
| 2,000 – 5,000원 미만 | 5원 |
| 5,000 – 20,000원 미만 | 10원 |
| 20,000 – 50,000원 미만 | 50원 |
| 50,000 – 200,000원 미만 | 100원 |
| 200,000 – 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

ETF·ETN 등은 별도 단위가 적용된다. 구간 경계에서는 **주문 가격이 속한 구간**의
단위를 쓴다.

```python
TICKS = [(2_000, 1), (5_000, 5), (20_000, 10), (50_000, 50),
         (200_000, 100), (500_000, 500), (float("inf"), 1_000)]

def tick_size(price: int) -> int:
    return next(t for bound, t in TICKS if price < bound)

def round_to_tick(price: float, side: str) -> int:
    # 매수는 내림, 매도는 올림: 의도보다 불리한 가격으로 체결되지 않게 한다.
    t = tick_size(int(price))
    return int(price // t * t) if side == "buy" else int(-(-price // t) * t)
```

경계 근처(예: 19,995 → 올림 시 20,000)는 반올림 후 **다시 그 가격의 호가단위로 검증**한다.

## 결제와 계좌

- 결제: **T+2** (영업일 기준).
- 종목별 증거금률이 있다. 100% 미만이면 미수가 생길 수 있다. 미납 시 반대매매가 나간다.
- 개인 공매도는 대주 제도 등으로 제한적이다. 2025-03 재개 이후 규칙을 증권사·금융위
  공지로 확인한다(미확인).
