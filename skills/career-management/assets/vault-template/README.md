# Career Vault

이 폴더는 경력의 단일 원천이다. 이력서·포트폴리오는 여기서 생성하는 파생물이다.
**비공개로 관리한다** (비공개 git 레포 권장).

| 파일 | 역할 |
|---|---|
| `profile.md` | 인적사항·학력·자격·타깃 직무 |
| `facts.md` | 잠긴 사실·금지 표현·공백 전략 — 생성 전 항상 먼저 읽는다 |
| `skills.md` | 기술 스택 마스터 (수준·근거 프로젝트) |
| `companies/` | 회사별 재직 정보 |
| `projects/` | 프로젝트 1개 = 파일 1개 |
| `applications/log.md` | 지원 이력 |
| `open-items.md` | 채워야 할 값 |
| `outputs/` | 생성한 제출본 |
| `sources/` | 가공 전 원천 자료 (권위 없음) |
| `CHANGELOG.md` | 변경 이력 |

점검: `python <skill>/scripts/check_vault.py <이 폴더>`
